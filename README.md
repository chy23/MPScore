## 🌟 試算表結構（每次考試一個獨立分頁）

### 1. 【學生名冊】分頁（管理防偽查詢代碼，一學期建一次即可）
| 欄位 | 欄位名稱 | 說明與範例 |
| :--- | :--- | :--- |
| **A 欄** | **班級** | 例：`701` |
| **B 欄** | **座號** | 例：`01` |
| **C 欄** | **姓名** | 例：`陳小明` |
| **D 欄** | **專屬代碼** | 系統隨機 6 碼（可點選試算表選單【⚡ MPScore 工具 > 一鍵產生防偽代碼】自動產生） |
| **E 欄** | **啟用狀態** | 填 `TRUE`（設為 FALSE 則該生無法查詢） |

> 💡 **極速同步小撇步**：只要在考試分頁貼上學生成績，點選試算表選單 **【⚡ MPScore 工具 > 🔄 從最新考試分頁同步名冊】**，系統就會自動將座號與姓名抓入【學生名冊】並一鍵生成專屬防偽代碼！

## 🚀 教師極速 4 步引導流程

```
[第 1 步：建立試算表] ➔ [第 2 步：貼上後端程式並發布] ➔ [第 3 步：連線檢測] ➔ [第 4 步：列印 QR Code 小卡]
```

1. **第 1 步：建立試算表**
   * 打開一張空白 Google 試算表（在網址列輸入 `sheets.new`）。
2. **第 2 步：貼上後端程式碼（只需做一次）**
   * 在試算表點選「擴充功能」>「Apps Script」。
   * 清空後貼上 `gas/Code.gs`，按儲存。
   * 重新整理試算表，點選上方選單 **【⚡ MPScore 工具 > 🛠️ 建立初始表格（空白試算表第一次使用）】**，系統瞬間幫您把名冊與兩次考試範本建置好！
   * 點右上角「部署」>「新部署」：
     - 類型選「網頁應用程式」
     - 執行身分選「我」
     - 誰可以存取選 **【所有人 (Anyone)】**（關鍵！）
   * **初次授權解鎖引導**：
     1. 點擊「審查權限」並選擇 Google 帳號。
     2. 看到警示別慌，點左下方灰色小字 **「進階 (Advanced)」**。
     3. 點選最底部 **「前往『未命名專案』(不安全)」**。
     4. 點擊藍色 **「允許 (Allow)」** 即可取得正式網址。
3. **第 3 步：在 MPScore 平台進行連線檢測**
   * 貼上網址按「⚡ 連線檢測」，系統自動讀取所有考試分頁與名冊。
4. **第 4 步：列印 A4 QR Code 家長通知單**
   * 點選「🖨️ QR Code 列印中心」，一鍵排版 A4 小卡發給家長！

## 🔒 家長端極致隱私保護：100% QR Code 零手動輸入

為徹底杜絕家長輸入同學姓名或猜測 6 碼代碼偷看他生成績的隱私漏洞：
* **家長端完全不提供文字輸入框**（不開放手動輸入學生姓名或查詢代碼）。
* **實體紙本通知單 QR Code 直達**：家長使用手機內建相機或 LINE 掃描通知小卡上的專屬 QR Code，點擊即可直達個人專屬成績。
* **網頁內建相機與相片辨識**：若直接打開網站，介面提供 `📷 開啟鏡頭掃描` 與 `🖼️ 選取通知單截圖辨識`，由程式自動解析專屬代碼載入報告。
* **學生姓名個資去識別化**：依據個資法保護規範，家長端呈現之學生姓名全自動去識別化（三個字名字中間替換為圈圈，例如「陳○明」；兩個字名字第二個字替換為圈圈，例如「陳○」），守護家庭隱私。
* **教師後台貼心快捷**：教師在後台體驗家長視角時，提供快速下拉選單，無需任何手動輸入即可秒切換預覽全班任一學生。

## 🍎 Apple Design & Apple HIG 人因工藝體驗標準全面落地

全系統（教師端後台、列印中心、獨立家長端）落實 Apple 人機介面指南與 WWDC 流體介面標準：
* **🍎 系統字型與微距優先**：首選 Apple 原生 `SF Pro Text / Display` 與 `PingFang TC（蘋方）`，搭配光學字距調諧，文字清晰銳利。
* **📱 iOS 原生抽屜工作表 (Bottom Sheet)**：移動端彈窗全數升級為符合 HIG 規範之底部抽屜卡，支援頂部圓角、拖曳導引把手（Grabber）與向下滑動手勢預備。
* **🎯 44×44 pt 觸控安全熱區**：所有關閉按鈕、切換項目與功能按鍵全面符合最低 44pt 感應區，杜絕行動裝置誤觸。
* **🫧 Apple Liquid Glass 通透工藝**：精確調校 `backdrop-filter: blur(20px) saturate(180%)`，輔以頂部 `1px` 捕光高光光邊，營造深邃層次感。
* **⚡ Apple HUD 浮動膠囊通知**：徹底汰除原生阻斷式 `window.alert()`，改採平滑動態島風格非同步 Toast，資訊傳達溫和不打斷操作。
* **🎛️ 內嵌式分段控制器 (Inset Segmented Controls)**：科目切換列全面採用 iOS 標準凹槽與白色浮起選中塊，視覺純淨自然。
* **🛡️ 安全邊界與無障礙降級**：全面支援 `viewport-fit=cover` 與 `safe-area-inset-*` 避免瀏海與手勢條遮擋；內建 `prefers-reduced-motion` 與 `prefers-reduced-transparency` 無障礙回退機制。
