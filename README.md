## 🌱 最新功能升級：單科抽離／額外採計雙軌精算引擎與個資去標籤化防護 (v3.2.0 - 2026-11-12)

1. **🌱 雙軌成績精算引擎（總平均與班級排名完整保留 × 單科統計精準排除） (`gas/Code.gs`, `index.html`, `parent.html`)**：
   - **個人總平均與班級排名完整保留**：受設定抽離考試之學生，其各科得分依然完整計入「個人總平均 (`studentAverage`)」並參與全班「總平均班級排名 (`studentRank`)」與總平均 PR 值。
   - **單科班級統計完全排除**：凡經設定為抽離／額外採計之科目，系統計算該科全班平均、四分位數 (`Q1`/`Median`/`Q3`)、最高/最低分、PR 百分等級、試卷難易度指數 ($P^*$) 及班級總平均時，全自動排除該生該科成績。
2. **🎛️ 教師端「抽離／額外採計科目設定」面板與雙重設定管道 (`index.html`, `gas/Code.gs`)**：
   - 於教師後台頂部導覽列、列印中心與手機沙盒新增 **「🌱 抽離／額外採計設定」** 專屬視窗，支援逐一點選每位學生需排除單科統計之科目，一鍵同步至試算表 `ScriptProperties` 與【學生名冊】G 欄。
   - 同時支援於考試分頁成績儲存格直接輸入星號前綴（如 `*85` 或 `＊85`），自動識別為該次測驗單科額外採計。
3. **💬 受設定學生家長端專屬溫馨呈現 (`parent.html`, `index.html`)**：
   - 受設定學生的家長端於該科目僅呈現學生個人得分與跨次自我進步幅度，自動隱藏該科班級平均、與班均差、PR 值及常模分佈曲線，並清楚顯示：**「該科目額外採計，該測驗不計入班級統計資料，僅呈現學生成績」**。
4. **🔒 資安與特教個資零洩漏防護**：
   - 一般學生家長端 API 僅接收排除抽離學生後的純淨班級統計，絕不回傳任何抽離名單；蜜蜂聚落圖全面去標籤化（統一呈現「在班級同儕常模中高於 X% 同學」），防止透過圓點數量反推班級抽離人數；抽離設定讀寫 API 強制綁定 `Teacher Key` 驗證與變更後 `bumpCacheEpoch_()` 瞬時刷新快取。

   - 移除前端與公開原始碼中之 School LINE Hub `APP_SECRET`，統一儲存於後端 `PropertiesService.getScriptProperties()` 並透過試算表 GAS 代理發送推播。
3. **👤 後端預先姓名遮罩與網址列/本機快取去識別化 (`gas/Code.gs`, `parent.html`)**：
   - 家長端 API (`action=query`) 於回傳前即在伺服器端將學生姓名遮罩為 `陳○明`；前端讀取 `?seat=&name=` 後立即以 `window.history.replaceState` 洗淨網址列明文參數，且 `localStorage` 快取鍵值與內容全面採用遮罩後姓名。
4. **🚦 「座號＋姓名」防暴力枚舉 (Rate Limiting) 與雙層快取提速 (`gas/Code.gs`, `gas/Loader.gs`)**：

   - 【家長閱覽紀錄】支援即時反映試算表手動刪除列之扣除統計，並自動維持 1,000 筆上限。

## 🚀 教師極速 4 步引導流程

```
[第 1 步：建立試算表] ➔ [第 2 步：貼上後端程式並發布] ➔ [第 3 步：連線檢測] ➔ [第 4 步：列印 QR Code 小卡]
```

1. **第 1 步：建立試算表**
   * 打開一張空白 Google 試算表（在網址列輸入 `sheets.new`）。
2. **第 2 步：貼上後端程式碼（只需做一次）**
   * 在試算表點選「擴充功能」>「Apps Script」。
   * 清空後貼上 `gas/Code.gs`，按儲存。
   * 重新整理試算表，點選上方選單 **【⚡ MPScore 工具 > 🛠️ 建立初始表格（空白試算表第一次使用）】**，系統瞬間幫您把名冊與兩次考試範本建置好！
   * 點右上角「部署」>「新部署」：
     - 類型選「網頁應用程式」
     - 執行身分選「我」
     - 誰可以存取選 **【所有人 (Anyone)】**（關鍵！）
   * **初次授權解鎖引導**：
     1. 點擊「審查權限」並選擇 Google 帳號。
     2. 看到警示別慌，點左下方灰色小字 **「進階 (Advanced)」**。
     3. 點選最底部 **「前往『未命名專案』(不安全)」**。
     4. 點擊藍色 **「允許 (Allow)」** 即可取得正式網址。
3. **第 3 步：在 MPScore 平台進行連線檢測**
   * 貼上網址按「⚡ 連線檢測」，系統自動讀取所有考試分頁與名冊。
4. **第 4 步：列印 A4 QR Code 家長通知單**
   * 點選「🖨️ QR Code 列印中心」，一鍵排版 A4 小卡發給家長！

## 🔒 家長端極致隱私保護：100% QR Code 零手動輸入

為徹底杜絕家長輸入同學姓名或猜測 6 碼代碼偷看他生成績的隱私漏洞：
* **家長端完全不提供文字輸入框**（不開放手動輸入學生姓名或查詢代碼）。
* **實體紙本通知單 QR Code 直達**：家長使用手機內建相機或 LINE 掃描通知小卡上的專屬 QR Code，點擊即可直達個人專屬成績。
* **網頁內建相機與相片辨識**：若直接打開網站，介面提供 `📷 開啟鏡頭掃描` 與 `🖼️ 選取通知單截圖辨識`，由程式自動解析專屬代碼載入報告。
* **學生姓名個資去識別化**：依據個資法保護規範，家長端呈現之學生姓名全自動去識別化（三個字名字中間替換為圈圈，例如「陳○明」；兩個字名字第二個字替換為圈圈，例如「陳○」），守護家庭隱私。
* **教師後台貼心快捷**：教師在後台體驗家長視角時，提供快速下拉選單，無需任何手動輸入即可秒切換預覽全班任一學生。
