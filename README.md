# 📊 MPScore - 智慧學生成績與學習診斷引導平台

> **目標：讓不擅長資訊科技的老師，也能在 5 分鐘內輕鬆發布具備高資安防護、個別雷達圖、歷年趨勢與學習診斷的家長成績查詢系統。**

### 2. 【成績明細】工作表
> 每次段考向下追加，系統會自動依據「座號」串聯歷年所有考試紀錄。
| 欄位 | 欄位名稱 | 說明與範例 |
| :--- | :--- | :--- |
| **A 欄** | **座號** | 例：`01`（對應學生名冊的座號） |
| **B 欄** | **學年度** | 例：`112` |
| **C 欄** | **學期** | 例：`1` |
| **D 欄** | **考試名稱** | 例：`第一次段考`、`第二次段考`、`期中評量`、`期末評量` |
| **E 欄** | **科目** | 例：`國文`、`數學`、`英語`、`自然`、`社會` |
| **F 欄** | **個人得分** | 例：`85` |

| **I 欄** | **解讀評語** | 可手動填入、由網站內建智慧引擎生成，或對接外部「成績單解讀平台」自動抓取 |

## 💡 特殊功能說明

### 1. PR 值由網站即時計算
* 老師在建立成績明細時，**不需要手動計算 PR 值**！
* 當全班同次考試各科得分輸入後，系統會在後端與網站端自動依據常模百分等級公式計算：
  $$\text{PR} = \text{Round}\left(\frac{\text{低於該分人數} + 0.5 \times \text{同分人數}}{\text{總人數}} \times 100\right)$$
  家長查詢時即可直接看見精準的 PR 值。

### 2. 解讀評語能連結網站抓取資料嗎？
**完全可以！支援以下三種方式串接：**
1. **外部 API 即時抓取**：若您的「成績單解讀平台」有提供 API / Webhook 接口，只需在 MPScore 後台設定 API 網址，家長查詢時網站會自動將分數傳送給解讀平台並即時抓回最新評語。
2. **試算表直連寫入**：若解讀平台也是透過 GAS 運作，可直接在產出評語後自動寫入【成績明細】的解讀評語欄。
3. **網站內建適性診斷**：若試算表未填且無外部 API，MPScore 網站會自動對比「個人得分 vs 班級平均」的差異，即時生成正向鼓勵與精進處方箋。

## 🚀 教師極速 4 步引導流程

```
[第 1 步：取得試算表範本] ➔ [第 2 步：貼上 Apps Script 程式] ➔ [第 3 步：一鍵連線檢測] ➔ [第 4 步：列印 A4 QR Code 小卡]
```

1. **第 1 步：建立試算表**
   * 按照上述欄位建立【學生名冊】與【成績明細】兩個分頁。
2. **第 2 步：貼上後端程式碼（只需做一次）**
   * 在試算表點選「擴充功能」>「Apps Script」。
   * 複製 `gas/Code.gs` 貼入並按磁碟圖示儲存。
   * 回到試算表按 F5，點上方選單【⚡ MPScore 工具 > 🛠️ 一鍵自動建立標準分頁與欄位】自動建置好分頁。
   * 點右上角「部署」>「新部署」（身分選「我」、存取選「所有人」），點擊「部署」。
   * **⚠️ 第一次部署授權解鎖指引**：
     1. 點擊「審查權限」並選取您的帳號。
     2. 看到「Google 尚未驗證這個應用程式」時**請別慌張**，點左下角灰色小字 **「進階 (Advanced)」**。
     3. 點選底部的 **「前往『未命名專案』(不安全)」**。
     4. 點擊 **「允許 (Allow)」**，即可順利取得正式網址！
3. **第 3 步：在 MPScore 平台進行連線檢測**
   * 貼上網址按「進行連線檢測」，亮綠燈即代表連線成功！
4. **第 4 步：列印 A4 QR Code 家長通知單**
   * 點選「🖨️ QR Code 列印中心」，系統自動排版 A4 一頁 8 張小卡，一鍵列印發送。

## 🔒 資安防護核心
* 試算表權限維持「私人」，外部家長無法檢視整份試算表。
* 隨機 6 碼 Token 防偽驗證，學生無法猜測同學代碼，絕不洩漏他人成績。
