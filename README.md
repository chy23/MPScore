# 📊 MPScore - 智慧學生成績與學習診斷引導平台

> **專為國中小與高中教師設計：每次考試就是一個新分頁，老師僅需貼上「各科原始分數」，其他所有「各科班級平均、個人總平均、班級排名、PR值、等第區間、學習診斷評語、跨次考試進退步對比」全交由網站全自動計算！**

---

## 🌟 試算表結構（每次考試一個獨立分頁）

### 1. 【學生名冊】分頁（管理防偽查詢代碼，一學期建一次即可）
| 欄位 | 欄位名稱 | 說明與範例 |
| :--- | :--- | :--- |
| **A 欄** | **班級** | 例：`701` |
| **B 欄** | **座號** | 例：`01` |
| **C 欄** | **姓名** | 例：`陳小明` |
| **D 欄** | **專屬代碼** | 系統隨機 6 碼（可點選試算表選單【⚡ MPScore 工具 > 一鍵產生防偽代碼】自動產生） |
| **E 欄** | **啟用狀態** | 填 `TRUE`（設為 FALSE 則該生無法查詢） |

> 💡 **極速同步小撇步**：只要在考試分頁貼上學生成績，點選試算表選單 **【⚡ MPScore 工具 > 🔄 從最新考試分頁同步名冊】**，系統就會自動將座號與姓名抓入【學生名冊】並一鍵生成專屬防偽代碼！

## ⚡ 老師免手動計算！網站全自動計算清單

| 項目 | 傳統做法（耗時） | MPScore 全自動處理 |
| :--- | :--- | :--- |
| **各科班級平均** | 老師手動打 `=AVERAGE()` 公式 | **網站/程式自動精算**，並於雷達圖與明細表即時比對 |
| **學生個人總平均** | 老師手動計算並拉公式 | **網站/程式自動精算**，顯示於家長端主儀表板 |
| **班級排名與名次** | 老師手動排 `=RANK()` 排序 | **網站/程式自動排名**，即時算出「第 X 名 / 全班 Y 人」 |
| **各科 PR 常模百分等級** | 老師需複雜常模公式或留空 | **網站自動即時換算 PR 值**（0 ~ 100 百分等級） |
| **各科等第落點分區** | 老師手動劃分區間 | **自動判定**（精熟表現、穩健發揮、努力成長、開發潛力） |
| **學習診斷適性處方箋** | 老師手動為每位學生寫幾百字評語 | **整合楊家驊老師 GradeInterpr 專家資料庫**，自動適性給予精進建議 |
| **歷次考試成長軌跡** | 老師難以跨表對比 | **自動比對所有考試分頁**，繪製歷次折線圖與各科「+4分 📈 / 持平」徽章 |

## 🚀 教師極速 4 步引導流程

```
[第 1 步：建立試算表] ➔ [第 2 步：貼上後端程式並發布] ➔ [第 3 步：連線檢測] ➔ [第 4 步：列印 QR Code 小卡]
```

1. **第 1 步：建立試算表**
   * 打開一張空白 Google 試算表（在網址列輸入 `sheets.new`）。
2. **第 2 步：貼上後端程式碼（只需做一次）**
   * 在試算表點選「擴充功能」>「Apps Script」。
   * 清空後貼上 `gas/Code.gs`，按儲存。
   * 重新整理試算表，點選上方選單 **【⚡ MPScore 工具 > 🛠️ 一鍵自動建立標準分頁範本】**，系統瞬間幫您把名冊與兩次考試範本建置好！
   * 點右上角「部署」>「新部署」：
     - 類型選「網頁應用程式」
     - 執行身分選「我」
     - 誰可以存取選 **【所有人 (Anyone)】**（關鍵！）
   * **初次授權解鎖引導**：
     1. 點擊「審查權限」並選擇 Google 帳號。
     2. 看到警示別慌，點左下方灰色小字 **「進階 (Advanced)」**。
     3. 點選最底部 **「前往『未命名專案』(不安全)」**。
     4. 點擊藍色 **「允許 (Allow)」** 即可取得正式網址。
3. **第 3 步：在 MPScore 平台進行連線檢測**
   * 貼上網址按「⚡ 連線檢測」，系統自動讀取所有考試分頁與名冊。
4. **第 4 步：列印 A4 QR Code 家長通知單**
   * 點選「🖨️ QR Code 列印中心」，一鍵排版 A4 小卡發給家長！

## 🔒 隱私與資安設計
* 試算表權限維持「私人」，外部家長無法檢視整份試算表。
* 隨機 6 碼防偽 Token，學生與家長只能查詢自己的個別成績與雷達圖。
