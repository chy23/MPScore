# 📊 MPScore - 智慧學生成績與學習診斷引導平台

> **目標：讓不擅長資訊科技的老師，也能在 5 分鐘內輕鬆發布具備高資安防護、個別雷達圖、歷年趨勢與學習診斷的家長成績查詢系統。**

---

## 🌟 解決現場老師的五大痛點

1. **不會寫程式、怕改壞試算表？**  
   提供「引導式 4 步設定精靈」，圖解說明與一鍵複製程式碼，連線狀態一目了然。
2. **擔心學生互相偷看成績、外流個資？**  
   後端採用「獨立隨機 Token 隔離驗證」，即使學生知道別人的學號或座號，也無法猜測出專屬驗證碼。
3. **教務處匯出的 Excel 成績是橫式的，不知道怎麼轉成資料庫格式？**  
   內建「橫式成績轉置小幫手」，直接複製貼上，一秒自動轉成標準明細！
4. **不知道怎麼印出個別 QR Code 給家長？**  
   內建「A4 通知單小卡列印中心」，自動將全班 QR Code 排版為一頁 8 張卡片，一鍵按列印即可裁切發送或貼在成績單上。
5. **發布前心裡不踏實，不知道家長手機打開長怎樣？**  
   內建「手機沙盒即時預覽」，老師在電腦前就能親眼檢驗家長看到的雷達圖與學習診斷評語。

## 🚀 教師極速 4 步引導流程

```
[第 1 步：取得試算表範本] ➜ [第 2 步：貼上 Apps Script 程式] ➜ [第 3 步：一鍵連線檢測] ➜ [第 4 步：列印 A4 QR Code 小卡]
```

### 步驟 1：建立專屬 Google 試算表
- 試算表內只需包含兩個標準分頁：
  1. `學生名冊`：學號、姓名、班級、座號、專屬代碼、啟用狀態。
  2. `成績明細`：學號、學年度、學期、考試名稱、科目、個人得分、班級平均、PR值、成績解讀與診斷建議。

### 步驟 2：貼上後端程式碼（只需做一次）
1. 開啟試算表上方選單：**「擴充功能」 > 「Apps Script」**。
2. 將本專案 `gas/Code.gs` 的內容完整貼入。
3. 點選右上角 **「部署」 > 「新部署」**：
   - 種類選擇：**網頁應用程式 (Web App)**
   - 執行身分：**我 (您的帳號)**
   - 誰可以存取：**所有人 (Anyone)** *(確保家長手機可正常讀取)*
4. 複製產生的網頁應用程式網址。

### 步驟 3：在 MPScore 平台進行連線檢測
- 將複製的網址貼在平台第 3 步的輸入框，點擊「⚡ 進行連線檢測」。
- 系統亮起綠燈即代表連線成功！

### 步驟 4：列印 A4 QR Code 家長通知單
- 點選「🖨️ QR Code 列印中心」，系統自動產生帶有專屬 QR Code 的小卡。
- 按下「列印 A4 通知小卡」，即可裁切發送！

## 🌐 如何啟用 GitHub Pages（提供常態性網址）

本專案已完全相容 GitHub Pages：
1. 將本專案 Push 至您的 GitHub 儲存庫 `https://github.com/chy23/MPScore.git`。
2. 進入儲存庫的 **Settings** > **Pages**。
3. 在 **Build and deployment** > **Branch** 選擇 `main` 分支與 `/(root)` 目錄，按 **Save**。
4. 幾分鐘後，您的專屬平台即可在 `https://chy23.github.io/MPScore/` 上線運作！

## 🔒 資安防護說明
- **試算表權限完全私密**：試算表無需設定公開共用，外部僅能透過 GAS 寫好的唯讀邏輯取得單筆已過濾資料。
- **後端安全隔離**：API 僅回傳查詢學生的個人數據，不洩漏任何其他同學姓名、座號或分數。
